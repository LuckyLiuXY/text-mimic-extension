# 网页文字模拟器（浏览器扩展）

两大功能：

1. 文字填充：保留任意网页的排版样式骨架，把页面文字整体替换为你自己的文本内容。
2. 小说阅读：上传整本小说 txt，在任意网页上弹出阅读器窗口，带目录跳转和进度记忆。

## 安装（Chrome / Edge 通用）

1. 打开 `chrome://extensions`（Edge 用 `edge://extensions`）
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录 `text-mimic-extension`
4. 工具栏点拼图图标，把「网页文字模拟器」固定出来

## 使用

### 文字填充

1. 打开任意目标网页（新闻、文档、后台系统都可以）
2. 点扩展图标，在「文字填充」页粘贴文本或上传 `.txt` / `.md` 文件
3. 点「填充到当前页面」：页面版式不变，文字全部换成你的内容
4. 点「还原原始内容」恢复；直接刷新页面也会恢复

### 小说阅读

1. 在「小说阅读」页上传 `.txt` 小说，自动按 第X章/卷/回、楔子、番外、Chapter N 识别章节目录
2. 点「在当前页面打开阅读器」：页面右上角弹出阅读窗口
3. 阅读器支持：目录侧栏跳转、上一章/下一章、字号调节、按住标题栏拖拽移动
4. 「融」按钮开启融入模式：自动采样当前页面的字体、字色、背景色，去掉边框阴影，小说文字伪装成页面原生段落
5. 「嵌」按钮开启内嵌模式：进入选点状态后点击页面任意段落，小说正文以真实 `<p>` 节点插入其后，完全继承页面原生样式（无 Shadow DOM、无附加样式）；插入位置记忆为 CSS 选择器，同站重开自动找回
6. 内嵌成功后主面板自动收起，右下角出现迷你控制条（半透明小胶囊，悬停展开）：上一章/下一章/目录/打开完整面板/退出内嵌
7. 内嵌内容跟随翻章/目录跳转同步更新；老板键将主面板、内嵌文字、迷你条一起全隐/全显
8. 菜单栏（标题栏）在鼠标离开约 1.5 秒后自动收成细缝，悬停展开；「钉」按钮固定后常显，取消钉住恢复自动最小化
9. 窗口可用右下角手柄缩放、标题栏拖动换位，位置和尺寸自动记忆，重开复原
10. 按老板键（默认 ` ，Tab 上方）一键隐藏/恢复；阅读进度自动保存，下次打开接着读
11. 老板键可在弹窗中自定义：点击按键框后按下新键即可，支持 Ctrl / Alt / Shift 组合键，阅读器中实时生效

## 选项说明

- 文本不够时循环填满整页：你的文本比页面容量短时，自动从头重复填充
- 保留按钮/导航等超短文字：跳过 8 字以内的文本节点，菜单和按钮不会被散文替换

## 实现要点

- `popup.js` 按需注入 `content.js`（`activeTab` + `scripting` 权限，不要求全站常驻权限）
- `content.js` 用 `TreeWalker` 收集可见文本节点，跳过 script/style/表单/可编辑区域
- 用户文本按中英文句读切句，按每个节点原始长度逐段分配，尽量保留段落节奏
- 首次替换前备份原文到内存 Map，支持一键还原；刷新页面天然还原
- 小说按章分存于 `chrome.storage.local`（已申请 `unlimitedStorage`）：`novelMeta` 存目录元数据（几 KB），`nov_<i>` 存每章正文。弹窗与阅读器打开只读元数据和当前一章，大书秒开
- 阅读器翻章时后台预取相邻章节，已读章节留在内存缓存；同一页面关闭重开零存储读取
- 阅读器 UI 挂在 Shadow DOM 中，与页面样式完全隔离；`z-index` 取最大值保证浮于顶层
- 文件读取自动识别编码：UTF-8 优先，非法字节即回退 GB18030（兼容国内下载站常见的 GBK 小说）
- 章节识别支持两套标题体系：`第X章/回/卷/节` 与起点系 `数字、标题`；`数字、` 需形成至少 5 章的递增链条才生效，防止正文编号列表误判

## 已知限制

- 浏览器内置页面（chrome://、新标签页、Chrome 应用商店、PDF 查看器等）禁止注入，无法使用
- manifest 已声明 `http://*/*` 与 `https://*/*` 的 host 权限；修改代码后需到扩展管理页点「重新加载」，并刷新目标网页
- 替换后如果页面自身 JS 重新渲染（如 SPA 切换路由），新内容不会被跟踪，需要再次填充
- 图片、头像、轮播等媒体内容不替换，只处理文字
- 章节识别依赖常见网文标题格式；极不规范的 txt 会退化为单章「全文」模式
- 部分下载站的 txt 里混有 `&larr;` 之类的网页残留字符，属于源文件问题，不影响阅读
